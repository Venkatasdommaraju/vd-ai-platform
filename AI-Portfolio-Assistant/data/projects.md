# Projects

REMS AI Assistant - Agentic AI and RAG Platform on AWS Bedrock (Jan 2025 - Present): the REMS project is the production agentic AI application behind the REMS (Restricted Entrance Management System) assistant, which handles search, eligibility decisions, and Q&A across 12 sites. It uses multi-agent orchestration with LangGraph and LangChain and tool-calling agents on Anthropic Claude through AWS Bedrock.

REMS AI Assistant, RAG work and tools: the RAG architecture he built covers document chunking, embeddings, metadata-filtered vector search, and re-ranking, with prompt engineering, structured outputs, and guardrails for knowledge retrieval over policy, training, and operational documents. The AI agents are integrated with REST APIs, SQL databases, and enterprise systems through reusable typed, schema-validated tools (Pydantic, MCP) and an LLM integration layer over Bedrock and Azure OpenAI with retries, streaming, and cost controls.

REMS AI Assistant, APIs and evaluation: the AI services are exposed as REST APIs in FastAPI with OAuth2/JWT role-based access, and real-time agent tokens are streamed over SSE and WebSocket, cutting time to first response from several seconds to under one second. Python evaluation suites in pytest (Recall@K, MRR, LLM-as-judge) gate every model, prompt, and retriever change. Deployment is gated GitHub Actions CI/CD to Docker and Kubernetes on Amazon EKS, with CloudWatch monitoring of latency, errors, and token cost.

Cloud-Based Restricted Area Access Management Modernization (Jan 2022 - Present): re-platformed legacy access-management capabilities onto AWS, with Python utilities that compare and reconcile training, HR (Snowflake), security-access, and Oracle master data with pandas, NumPy, and openpyxl, with automated pytest suites. The daily data loads are monitored with CloudWatch, with 99.5% meeting their 7 AM SLA.

Technology Cost & License Intelligence Platform (Jan 2026 - Present): built and deployed independently, from concept to production: Python FastAPI services, a React/TypeScript dashboard, and a pandas data preparation and feature engineering pipeline that models software-license spend by management hierarchy. It integrates local and enterprise AI (Ollama, Qwen, Microsoft Copilot) for cost analysis with no data sent to external LLM providers, uses Dataiku for data preparation and SageMaker to train and evaluate anomaly-detection and forecasting models, and is deployed to ECS Fargate with Terraform and GitHub Actions.

Aseptic Area Access Management & Compliance Platform (Jan 2019 - Present): a regulated access-management and reporting solution that compares personnel, training, security-access, and environmental-monitoring data to control entry into aseptic manufacturing areas across multiple sites. It has a 17-table Oracle data model with 60+ PL/SQL stored procedures and audit tables, BIOVIA Pipeline Pilot workflows, Python FastAPI services with a React frontend, and Celery/Redis workers that run bulk eligibility checks at 1,000+ records/sec.

Environmental Monitoring Data Analytics Platform (Sep 2019 - Dec 2019): Pipeline Pilot workflows and Python/SQL pipelines consolidating environmental-monitoring data from Oracle and SQL Server into curated datasets for cross-site analytics and reporting.

Manufacturing Batch Tracking & Data Integration Platform (Sep 2016 - Nov 2018): Pipeline Pilot workflows, Oracle SQL and PL/SQL packages, and Python/Django services and REST APIs for a batch-tracking and analytics application integrating manufacturing, quality, and LIMS data (ERP, electronic batch record, LabWare, and quality systems) across sites.

Regulatory Data Migration & Legacy System Modernization (Oct 2015 - Mar 2016): migrated regulatory change-management records from a legacy system and Excel-based records into a new product dossier management system, with automated extraction, transformation, mapping, and loading in BIOVIA Pipeline Pilot 9.0.2 and Oracle PL/SQL, source-to-target validation, reconciliation, and GxP data-integrity evidence.

Personal open-source projects (not part of his work at Pfizer): this AI Portfolio Assistant, a RAG service with FastAPI and a TF-IDF retriever; a LangGraph multi-agent microservice with a planner, retriever, analyst and critic; an IoT sensor anomaly detector built with scikit-learn and FastAPI; an environmental-monitoring excursion predictor trained on synthetic data; and a Snowflake data platform demo.
